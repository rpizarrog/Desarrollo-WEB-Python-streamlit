# Estadística Descriptiva con Python y Streamlit

## Descripción

Aplicación web desarrollada con **Python** y **Streamlit** para apoyar el aprendizaje de la Estadística Descriptiva.

La aplicación permite generar datos aleatorios con distribución Normal, visualizar sus principales estadísticos descriptivos y representarlos gráficamente mediante histogramas y diagramas de caja.

Este proyecto forma parte de la asignatura **Programación y Desarrollo Web con Python**.

---

## Características

- Generación de datos aleatorios con distribución Normal.
- Definición de:
  - Número de observaciones.
  - Media.
  - Desviación estándar.
  - Semilla.
  - Etiqueta de la variable.
- Visualización de los datos como:
  - Texto.
  - DataFrame.
- Estadísticos descriptivos.
- Histograma.
- Diagrama de caja.
- Visualización simultánea del histograma y diagrama de caja.
- Arquitectura basada en Programación Orientada a Objetos.

---

## Tecnologías utilizadas

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
